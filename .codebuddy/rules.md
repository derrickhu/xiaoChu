# 项目规则

## 数据库安全
- **绝对禁止**主动执行任何数据库写入、更新、删除操作（包括云数据库、本地存储等）
- 数据库操作只能由用户通过管理工具界面手动触发，AI 不得代为执行
- 需要查询数据库时，只能读取本地已导出的 JSON 文件，不得直接调用云 API

## 抖音上线分支与多平台兼容
- 抖音上线/适配工作使用独立分支 `platform/douyin`，不要直接在 `main` 上做抖音专用改动。
- 后续改动应尽可能保持微信与抖音双端兼容；除非用户明确要求，否则不能为了抖音破坏微信现有行为。
- 平台差异优先收敛到 `js/platform.js`、平台配置文件或小型适配层；业务逻辑中避免直接散落 `wx` / `tt` 等平台 API 调用。
- 新增平台能力时必须提供降级或空实现，确保不支持该能力的平台不会报错。
- 修改打包/项目配置时，优先维护平台源配置，并确保微信配置与抖音配置的差异清晰、可回退。
